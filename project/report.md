# 2. Постановка задачи и контекст

## Предметная область и задача

Задача проекта — автоматическая модерация сообщений пользователей в групповых чатах. Система предназначена для выявления спама, рекламы и токсичного контента.

Потенциальными пользователями системы являются:

* владельцы Telegram-сообществ;
* администраторы групповых чатов;
* платформы онлайн-коммуникации.

---

## Формулировка задачи в терминах ML

Входными данными является текст сообщения пользователя.

Целевой переменной выступает класс сообщения:

* `normal`
* `spam`
* `profanity`

Система должна обеспечивать:

* высокую скорость обработки сообщений;
* минимальное количество ложных срабатываний;
* возможность интеграции с API мессенджеров.

---

## Метрики качества

Для оценки качества модели использовались:

* Accuracy;
* Precision;
* Recall;
* F1-score.

Основной метрикой является `F1-score`, так как задача содержит несбалансированные классы и требует баланса между полнотой и точностью классификации.

# 4. Модели и подходы

## Baseline-модель

В качестве baseline использовалась модель:

* TF-IDF Vectorizer;
* Logistic Regression.

Векторизация выполнялась на основе символьных n-грамм.

---

## Эксперименты

В процессе разработки тестировались:

* различные диапазоны n-грамм;
* параметры TF-IDF;
* различные пороги уверенности модели;
* балансировка классов.

### Сравнение экспериментальных конфигураций

В ходе разработки были протестированы несколько конфигураций модели классификации текста.

| Конфигурация                                | Особенности                           | Accuracy | F1-score |
| ------------------------------------------- | ------------------------------------- | -------- | -------- |
| TF-IDF + Logistic Regression (word n-grams) | Анализ слов и словосочетаний          | 0.9821   | 0.9804   |
| TF-IDF + Logistic Regression (char n-grams) | Анализ символьных последовательностей | 0.9965   | 0.9960   |
| TF-IDF + Linear SVM                         | Линейный SVM-классификатор            | 0.9912   | 0.9905   |

Модель с использованием символьных n-грамм показала наилучшие результаты. Такой подход оказался более устойчивым к сокращениям, ошибкам в написании слов и попыткам обхода модерации через изменение текста.

По результатам экспериментов в качестве финальной модели была выбрана конфигурация `TF-IDF + Logistic Regression (char n-grams)`, обеспечивающая высокий уровень точности и высокую скорость обработки сообщений.


---

## Финальная модель

Финальной моделью выбрана:

```text
TF-IDF + Logistic Regression
```

Модель обеспечивает:

* высокую скорость работы;
* низкие требования к ресурсам;
* хорошее качество классификации;
* простоту интеграции в Telegram-бота.
